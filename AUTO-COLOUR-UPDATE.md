# Automatic product colour selector update

Updated 7 Oct 2026.

- Removed the storefront "View all colours" option.
- Splits combined colour text such as "Blue pink black yellow brown nude" into individual customer-facing colour choices.
- Selecting a colour changes the main product image.
- Clicking a recognised colour thumbnail can sync the colour selector.
- Uses saved colour-to-photo mappings first, then attempts automatic image-colour matching for common colours.
- Existing inventory/checkout variant IDs are retained so this storefront fix does not manufacture duplicate stock.
